AegisAI API reference.

A local API for decision assessments and recorded human reviews.

Endpoints

GET /health
Application health and version.
GET /api/status
Configured Ollama model availability.
GET /api/samples
Available fixed examples and their matching briefs.
POST /api/assess
Validate a brief, generate or load its assessment, apply policy and save the record. Returns 201 on completion; 502 saves a failed attempt with no score. Invalid input returns 422 without creating a record.
GET /api/assessments
Latest 500 records and total saved count.
GET /api/assessments/{id}
A saved record, its provenance and review history.
POST /api/assessments/{id}/review
Append a review with action, reviewer, note and expected_version. A stale version or failed assessment returns 409.
GET /api/assessments/{id}/export/md
Download a Markdown report including review events.
GET /api/assessments/{id}/export/json
Download the structured record.

Example live request

POST /api/assess
Content-Type: application/json

{
  "title": "Pilot an internal documentation refresh",
  "decision": "Pilot the new internal portal with ten volunteers for two weeks.",
  "constraints": "Retain the existing portal throughout the pilot.",
  "owner": "Enablement team",
  "category": "Operations",
  "appetite": "Cautious",
  "mode": "live",
  "sample_id": null
}

For sample mode, use the exact brief returned by /api/samples and its sample_id. Edited sample briefs are rejected. API clients are responsible for submitting a trusted local request; the application blocks cross-origin browser writes.
